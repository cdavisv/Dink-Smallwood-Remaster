`BuildFootprint` projects actual cooked vertices into world XY, computes their strictly convex CCW hull, and uses actual four screen corners for logical pixel-centre sampling. It rejects invalid/folded maps, nonfinite/degenerate geometry, clipped off-screen bodies and empty logical masks. `LogicalCells` are Y-major and are an explicit **cell-centre approximation**, not conservative dilation or exact arbitrary query geometry. Maximum half-cell world radius is recorded as the boundary quantization bound. Exact mesh physics remains authoritative for capsule/projectile/body contact; interaction must consume the same polygon/body rather than revert to the old giant rectangle.
