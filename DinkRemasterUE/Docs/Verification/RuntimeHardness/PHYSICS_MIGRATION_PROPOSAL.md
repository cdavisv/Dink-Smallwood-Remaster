# Physical migration source successor

This branch now implements a registered physical owner, world-capability subsystem, descriptor reader/producer and explicit editor foundation/staging tools in source. These UE files have not been compiled or executed. No project Data, Content, native modules or worlds changed. Old source-proposal21/adapter receipts are historical; the physical successor records its current dependencies separately.

`UDinkRuntimeHardnessWorldSubsystem::RequiresScreenCapability` requires an actual tagged greybox host. Sidecars and ordering columns alone never activate new behavior. `AcquireOrRearm` verifies descriptor-bound Gameplay inputs, unique host/volume, actual cooked immutable geometry, world identity, profiles, all64 response entries, navigation/overlap policy, and authored-art exclusion before returning a retained owner. Corrupt marked worlds fail closed. Unmarked worlds retain legacy ordering and collision. Authored collision screens must remain unmarked; they need a separate authored ownership design.

`build_runtime_hardness_descriptors.py` produces descriptors only into explicit external output. Its art-aware `activation_plan` excludes authored screens and never publishes markers. All644 descriptors are source authority, not644 migrated screens. `UDinkHardnessFoundationLibrary::PrepareFoundationV1` creates only new unsaved versioned foundation assets: old ground quad plus fill_solid, and separate fill_water. Tile/sprite/warp masks move to the mutable code/owner partition. Existing importer behavior, asset manifest and aggregate meshes are untouched.

`StageFoundationHostV1` is the concrete next staging helper. It accepts only an explicitly empty host in a new `/Game/Dink/RuntimeHardnessV1/Worlds/` editor world, rejects duplicate screen hosts/volumes and existing/tagged collision, requires the complete explicit art-manifest list and excludes both declared and actually applied authored collision. It validates descriptor bindings and versioned source meshes before assigning this new host. Actual registered source/cooked triangle and policy verification must pass before marker publication; refusal clears its own assigned meshes and restores tags/transform. It does not save packages or copy a source world. The caller must build the new stage with unchanged render actors, warps, screen volumes and all other original controls. This helper remains uncompiled; no marker was published.

## Per-draw transaction

The pure Session computes a candidate map and exact owner/code rectangles first. `RegisteredHardnessOwner` allocates/registers real static non-simulating triangle bodies, copies full policy and validates them with query/simulation flags disabled. The original prism is open-bottom, top plus four sides; shared source/cooked winding follows installed UE/Chaos cooking. A closed convex substitute would change low-only queries and is not used.

Commit revalidates lifetime and both body sets under the scene write operation, exchanges actual shape query/simulation flags, refreshes acceleration state, rolls back on validation failure, and publishes logical map plus adapter journal in the same callback. Old bodies remain until exchange succeeds. No aggregate toggle, global collision weakening or actor visibility shortcut is used. Standard asynchronous navigation updates follow the physical transaction; atomic navigation is not claimed.

Initial admission publishes the projected tile/base-main/initial-mixed journal before script reads. Original editor type/numeric picture state persists; raw hit-map residuals and transient editor hard flags do not persist across ordinary save/load. Forced same-screen rebuilding has different original lifecycle rules; adapter phases and current review fixes are owned in ADAPTER_PHASES.md. Both hardness clear and stamp use displayed pseq/pframe only; combat GetHardbox remains unchanged.
