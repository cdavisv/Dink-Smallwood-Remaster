# Stonebrook interior vista V3 — Work-only source candidate

This scene gives the starting house a coherent courtyard and village view through its door and side windows. It is contextual art, independent of the native camera/frustum correction. Nothing here has been imported or published to game Data. No Stage/Main C++, `.uasset` or ledger was written by this task.

Use `PreviewV3/inside-door.png`, `inside-west-window.png` and `inside-east-window.png`, paired by `PreviewV3/preview_contract.json`. The base-folder PNGs are archived rejected preliminary views, and PreviewV1/V2 remain iteration evidence. These are Cycles CPU source renders at1280×720, not game screenshots. Borrowed oak collars/root seams, old material finish and a finite backdrop remain visible candidate limitations; this is not final realistic art acceptance.

`Stonebrook_InteriorVista_Candidate_V3.blend` contains the editable composition. `Stonebrook_InteriorVista_PreviewV3.blend` additionally stores preview cameras/daylight. The new-assets validator passes55/55 with zero errors or warnings.
