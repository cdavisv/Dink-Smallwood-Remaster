# Milder soldier art candidate

Original plate armor, blue gambeson/waist cloth and leather equipment over a distinct mature, stockier MakeHuman male profile. The reference is the original `401/01` soldier sprite: brown hair, steel/leather, blue cloth, no helmet. This replaces Milder's generic presentation during the mandatory `s1-bul` feeding cutscene; it does not change that script's sequence changes or movement.

Anatomical base, skin, eyes, brows/lashes and selected `short04` hair come from the official CC0 MakeHuman system assets already cached for the project. Selected hair sources are retained in `ThirdParty/MakeHuman/hair/short04`; the shared anatomical/eye/skin inputs and retained licences are under `Characters/ThirdParty/MakeHuman` and `Characters/Provenance`. Primary [asset licence](https://github.com/makehumancommunity/mpfb2/blob/master/LICENSE.ASSETS.md), [official asset pack](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html). No new paid generation/downloads were used. The wardrobe geometry and procedural textures are original project work.

The Epic reference skeleton is separate project data, not CC0 authored anatomy. No Epic robot geometry is present in the final source/export; it is used only transiently for surface-weight transfer. All89 names/parents/rest transforms retain the existing `/Game/Characters/Mannequins/Meshes/SK_Mannequin` contract. Source remains metres; only the export process copy scales mesh/edit-bone positions100 and uses scene unit.01/FBXheader1. Explicit identity root, wrapper `Armature`, no leaf bones or new roots. See the shared `Characters/README.md` for the empirically verified bind-pose rationale.

## Build

Use Blender5.2.2LTS and the existing MPFB tool cache at `/tmp/dink-mpfb2`; asset cache `/tmp/dink-mpfb-user/data`. Run `Tools/create_milder_base.py`, `build_milder_art.py`, `rig_milder.py`, `bake_milder_atlas.py`, then `finalize_milder.py` in separate background processes. The profile uses male1, age.59, muscle.76, weight.64, height.55 before landmark fitting; the final face is broader and the silhouette slightly taller than Dink. Hair/eyes and skin are adjusted together so fitted features stay aligned.

Steel breast/back plates use smooth measured torso profiles, with separate overlapping waist lames and rivets. Shoulder caps, vambraces and greaves are curved forged shells, with leather baldric/belt/boots and blue waist cloth. The corrected neckline is a single body-fitted cloth surface over complete retained neck skin; old cut-shirt/binding patches were removed. This avoids the prior jagged voids and detached collar strips. Plate pieces have rigid masks for appropriate spine/limb bones; cloth and skin retain normalized surface weights, max4 influences. Detailed anatomy is preserved while wardrobe reductions keep the NPC below35k triangles. Final LODs have32,674/16,337/8,168/3,921 triangles; source validator reports zero errors. All face-less edges are stripped after decimation. The two remaining3-face edges are waist-clothing junctions at[-5.39,-16.14,98.89]cm and[7.87,4.93,103.42]cm, documented in `milder_lod_report.json` for candidate topology review; no face topology was changed during export cleanup. Intentional open skin-under-clothing, cloth and hair boundaries remain. Actual LOD0 height is182.935cm, near the1.85m target; manifest bounds are measured, not assumed.

Five material families share one unique-UV4096 BC+alpha/N/ORM atlas set. The ORM metallic channel preserves steel while cloth/leather remain nonmetallic. Hair/brow/lash slots use masked two-sided shading; steel remains opaque. Source `.blend` retains the full PBR graphs; export-only graphs are cleared after source saving because the Unreal importer consumes manifest PNGs explicitly.
