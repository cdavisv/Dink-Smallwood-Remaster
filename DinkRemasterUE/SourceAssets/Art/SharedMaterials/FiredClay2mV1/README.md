# Shared fired-clay2m

Two reusable material roles, six new BC/N_GL/ORM1024maps and three exact existing Soot2m dependencies. registry.json defines the opaque generic layered parent; PROVENANCE.md retains CC0 attribution/scale and artist-finish qualifications. No prop atlas, world-position lookup or private bake.

SharedFiredClayLibrary_Source.blend is a self-contained packed material library. Tools/build_library.py defaults to it; use --out with a distinct file for safe replay. GenericReuse_2m4m.blend and Review/generic_reuse_2m4m.png show8independent2m/4m clear/sooted panels. VertexAlpha controls soot coverage while surfaceopacity stays1. Normal strength1, GL+Y normals need nativegreenflip. No native factory/import/game approval is claimed.
