# Shared mineral masonry2m

Three reusable registered source materials: LimeMortar2m, Soot2m and FieldstoneCoursed2m. Each is BC/N_GL/ORM1024px per2m; OpenGL normals require green flip on native DirectX import. registry.json and PROVENANCE.md define the actual uniform parent and artist/CC0 qualifications.

SharedMineralMasonry_Source.blend contains only these packed material graphs. Tools/build_library.py defaults to this portable registered source; pass a distinct --out for a safe replay. Existing FieldstoneSeed2m, IronLead2m and OakLonggrain2m are reused, not re-registered or aliased. No native activation or final appearance approval.
