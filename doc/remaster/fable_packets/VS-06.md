## 7. Import and binding

- Meshes: `DINK_KIT=Structures/Misc DINK_KIT_FOLDER=Structures Scripts/import_town_exteriors.sh` (cottages, bridge, island
  pieces) and `DINK_KIT=Structures/Castle DINK_KIT_FOLDER=Structures Scripts/import_town_exteriors.sh` (castle kit), one
  Unreal step each through `unreal_turn.sh`; new sources go into `Structures/<Kit>/` with `manifest.json` +
  `modules.json` (the importer refuses while an FBX is newer than the manifest).
- Sets: `python3 -I Scripts/assemble_structures.py` (needs `ImportData/` from a world export and `tools/dinkex/out`), then
  `python3 -I Scripts/PhotorealQA/structure_walk_check.py` (exit 1 over 0.5 m2 of solid on walkable ground per set).
- Row format (`structure_sets.json`, per screen): `houses: [{id, kind, note, modules: [{mesh, px: [map x, y], offset_cm,
  yaw, scale}], parts}]`, `footprints`, `stands_for` (card -> set that replaces it). Hide lists come from `stands_for`.

- Church meshes: Unclaimed kit (`make_kit_manifest.py --all` lists them; import as in IMPORT.md "Unclaimed families kit").
